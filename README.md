# ML MIPT 2025 — соревнования Kaggle

Решения трёх соревнований курса ML MIPT 2025: регрессия на табличных данных, бинарная классификация и поиск ключевых точек на изображениях.

| Соревнование | Задача | Метрика | Сроки |
|---|---|---|---|
| Contest 1 — алмазы | Предсказание стоимости алмаза по его характеристикам | MAE ↓ | 24.09.2025–27.10.2025 |
| Contest 2 — Dota 2 | Предсказание вероятности победы команды Сил Света | ROC-AUC ↑ | 31.10.2025–01.12.2025 |
| Contest 3 — коты | Определение координат ключевых точек на изображении | Columnwise MAE ↓ | 01.12.2025–12.01.2026 |

## Contest 1 — стоимость алмазов

**Цель:** построить модель регрессии, предсказывающую стоимость алмаза по доступным характеристикам.

**Оценка:** средняя абсолютная ошибка (MAE). Тестовая выборка разделена поровну между public и private лидербордами; итоговый рейтинг определяется по private части.

**Формат решения:** CSV со столбцами `id,price` — одно предсказание стоимости для каждого объекта тестовой выборки.

## Contest 2 — исход матча Dota 2

**Цель:** решить задачу бинарной классификации — оценить вероятность победы команды Сил Света (Radiant).

**Оценка:** ROC-AUC.

**Формат решения:** CSV со столбцами `match_id,radiant_win`. Значение `radiant_win` — вероятность в диапазоне от 0 до 1.

## Contest 3 — ключевые точки на изображениях котов

**Цель:** предсказать положение девяти ключевых точек: рта, двух глаз и по три точки на каждом ухе. Для каждой точки определяются координаты `(x, y)` — всего 18 целевых переменных.

**Оценка:** Columnwise MAE — среднее значение MAE по 18 координатным столбцам.

**Результат предсказания:** 18 координат для каждого изображения тестовой выборки. Для соревнования предоставлен отдельный шаблон в корне репозитория курса.
